# 🚨 Emergency Equipment Management System

A web-based system developed to manage and monitor emergency equipment inside organizations such as hospitals, companies, and emergency centers.

---

## 📌 Project Description

The Emergency Equipment Management System helps organizations efficiently manage emergency tools and equipment such as:

- Fire Extinguishers
- Oxygen Tanks
- First Aid Kits
- Defibrillators (AED)

The system allows administrators and employees to track equipment information, expiration dates, categories, and availability status.

---

## 🎯 Features

- 🔐 Admin Login System
- 📦 Equipment Management (CRUD)
- 🗂️ Categories Management
- 👨‍💼 Employee Management
- 📅 Expiration Date Tracking
- 📊 Equipment Availability Monitoring
- 🛠️ Edit & Delete Equipment
- 🌐 Responsive User Interface
